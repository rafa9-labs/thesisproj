## Data Strategy Summary

| Data | Source | Mode | Why |
|------|--------|------|-----|
| Live bid/ask/mid | **OANDA PricingInfo** (REST) | 3s polling | Real-time current price. No WebSocket complexity yet. |
| Sparkline OHLCV (last 50 bars) | **SQLite candles** table | Instant query | Already in DB. One indexed query per pair. Offline. |
| Full candlestick chart (200 bars) | **SQLite candles** table | Instant query | Same table, larger limit. M15/M30/H1/H2 supported. |
| Backtest trade chart OHLCV | **SQLite candles** table | Instant query | Candles for the backtest date range (pair+timeframe). |
| Trade markers (entry/exit) | **SQLite jobs** table | Parse result JSON | Trade timestamps joined with candle closes → prices. |
| OANDA API key | **secure.db** (encrypted) | Read on each poll | User's own key from Settings. Fallback to `.env` for dev. |

## Step 1 — `DataStore.get_latest_candles()` *(10m)*

**File**: `pipeline/data_sqlite.py` — new method after `get_candles()`

```python
def get_latest_candles(self, pair: str, timeframe: str, limit: int = 100) -> pd.DataFrame:
    """Return the most recent N candles for a pair+timeframe, most recent last."""
    with self._cursor() as (conn, cur):
        cur.execute(
            "SELECT ts, mid_open, mid_high, mid_low, mid_close, "
            "bid_open, bid_close, ask_open, ask_close, spread, volume "
            "FROM candles WHERE pair=? AND timeframe=? ORDER BY ts DESC LIMIT ?",
            (pair.upper(), timeframe, limit),
        )
        cols = [d[0] for d in cur.description]
        rows = cur.fetchall()
        if not rows:
            return pd.DataFrame(columns=cols)
        df = pd.DataFrame(rows, columns=cols)
        df.rename(columns={"ts": "time"}, inplace=True)
        df["time"] = pd.to_datetime(df["time"], utc=True)
        for c in ("mid_open","mid_high","mid_low","mid_close","bid_open","bid_close","ask_open","ask_close","spread"):
            if c in df.columns:
                df[c] = df[c].astype("float32")
        return df.sort_values("time").reset_index(drop=True)
```

## Step 2 — `GET /prices/live` *(1h)*

**File**: New `api/routers/prices.py`

```
GET /api/v1/prices/live?pairs=EURUSD,GBPUSD,USDJPY&lookback_bars=50

Response 200:
{
  "prices": [
    {
      "symbol": "EURUSD",
      "bid": 1.10412,
      "ask": 1.10432,
      "mid": 1.10422,
      "spread_pips": 0.2,
      "change_pct": 0.12,
      "timestamp": "2026-05-05T21:30:00Z",
      "sparkline": [
        {"t": 1777990000, "v": 1.1040},
        {"t": 1777990100, "v": 1.1041}
      ]
    }
  ],
  "source": "oanda"
}

Response 200 (no key):
{
  "prices": [],
  "source": "key_required",
  "message": "Add your OANDA API key in Settings to see live prices."
}

Response 503 (OANDA unreachable):
{
  "prices": [],
  "source": "unavailable",
  "error": "OANDA API unreachable"
}
```

**Implementation details**:

1. **Read OANDA key**: from `SecureStorage` (`api_keys` table, `key_name="oanda"`). Fallback: `os.environ.get("OANDA_ACCESS_TOKEN")`. If neither → return `key_required`.

2. **PricingInfo call**:
   ```python
   from oandapyV20 import API
   from oandapyV20.endpoints.pricing import PricingInfo
   import oandapyV20.endpoints.pricing as pricing_endpoint
   
   # Build OANDA instrument names (EUR_USD, GBP_USD, etc.)
   from pipeline.pair_config import get_pair_config
   instruments = ",".join(get_pair_config(p).oanda_name for p in pairs)
   
   api = API(access_token=token, environment="practice")
   r = PricingInfo(accountID, params={"instruments": instruments})
   api.request(r)
   prices_data = r.response["prices"]
   ```

3. **Sparkline data**: per pair, call `DataStore.get_latest_candles(pair, "M30", lookback_bars)`. Extract `time` (epoch) and `mid_close` → `[{t, v}]`.

4. **change_pct**: `(sparkline[-1].v - sparkline[0].v) / sparkline[0].v * 100`

5. **Edge cases**:
   - Pair has no candles in DB → sparkline is empty `[]`
   - OANDA returns `status: "non-tradeable"` for a pair → set bid/ask/mid to null
   - OANDA timeout or connection error → return `unavailable`

**AccountID sourcing**: Read from `os.environ.get("OANDA_ACCOUNT_ID")` or SecureStorage `kv_store` table key `"oanda_account_id"`.

```typescript
export function useLivePrices(pairs: string[], lookbackBars = 50) {
  return useQuery({
    queryKey: ["live-prices", pairs, lookbackBars],
    queryFn: async () => {
      const { data } = await apiClient.get<LivePricesResponse>("/prices/live", {
        params: { pairs: pairs.join(","), lookback_bars: lookbackBars },
      });
      return data;
    },
    refetchInterval: 3_000,
    staleTime: 2_000,
    retry: 1,
  });
}

export function useCandles(pair: string, timeframe: string, limit = 200) {
  return useQuery({
    queryKey: ["candles", pair, timeframe, limit],
    queryFn: async () => {
      const { data } = await apiClient.get<CandlesResponse>(`/candles/${pair}/${timeframe}`, {
        params: { limit },
      });
      return data;
    },
    staleTime: 15_000,
    enabled: !!pair && !!timeframe,
  });
}

export function useTradeChartData(jobId: string, model: string) {
  return useQuery({
    queryKey: ["trade-chart-data", jobId, model],
    queryFn: async () => {
      const { data } = await apiClient.get<TradeChartData>(`/backtest/${jobId}/trades/chart-data`, {
        params: { model },
      });
      return data;
    },
    enabled: !!jobId && !!model,
    staleTime: Infinity,
  });
}
```

## Step 8 — `GET /backtest/{id}/trades/chart-data` *(1h)*

**File**: `api/routers/backtest.py` — new endpoint

```
GET /api/v1/backtest/{jobId}/trades/chart-data?model=xgboost

Response 200:
{
  "pair": "EURUSD",
  "timeframe": "H1",
  "candles": [
    {"t": 1777990000, "o": 1.1040, "h": 1.1045, "l": 1.1038, "c": 1.1043, "volume": 45}
  ],
  "trades": [
    {"trade_id": 1, "entry_time": 1777990000, "exit_time": 1777995000,
     "direction": "BUY", "entry_price": 1.1043, "exit_price": 1.1051, "pnl_pct": 0.072}
  ],
  "equity_curve": [
    {"time": 1777990000, "value": 1.000},
    {"time": 1777995000, "value": 1.001}
  ]
}
```

**Implementation**:

1. Load job from DataStore → get `config` (pair, timeframe, start_date, end_date, models)
2. `DataStore.get_candles(pair, timeframe, start_date, end_date)` → candle bars
3. Parse `result.metrics[]` → find the model's trade log
4. Build trade markers:
   - Read raw trade DataFrame (from `execution_utils.build_trade_log_from_df` format)
   - For each trade: `entry_time` → find candle at that timestamp → use `mid_close` as `entry_price`
   - Same for `exit_price`
   - Map `side:"long"` → `direction:"BUY"`, `side:"short"` → `direction:"SELL"`
   - `entry_time`/`exit_time` → epoch seconds
5. Extract `equity_curve` from model's metrics
6. Convert candles to `[{t, o, h, l, c, volume}]` format (time → epoch)

**Edge cases**:
- Job has multiple models → filter by `?model=` param
- Trade entry/exit timestamp doesn't exactly match a candle → find nearest previous or next candle (≤ 1 bar tolerance)
- Model has no trades → trades `[]` → chart shows candles only
